# CLAUDE.md

## Project
Algolytics (repo: DSA-Visualiser-NEA) is an A-level Computer Science NEA: a desktop learning tool for
data structures and algorithms. It has a main menu with search/filter, revision pages, timed quizzes,
and animated visualisers (array, queue/priority/circular queue, stack, linked list, graph, tree/binary
tree, sorting, searching).

## Stack
- Python 3 + CustomTkinter/Tkinter (UI), networkx + matplotlib (graph/tree drawing), Pillow (icons).
- Entry point: `Main.py` (`App` class). Each visualiser is a module `*_vis.py` exposing `main(master, window)`.
- `Quiz.py` holds the `Question` class and the question pool.
- Revision content lives in `DSA Types Database.txt` (one dict per line, placed by a hash function).
  It is generated by `making and testing hash with the database for dsa types.py`; `Main.hashDataRetrieve`
  reads it. Edit content in the generator script, then regenerate — don't hand-edit the .txt.
- Several files start with a comment block mapping sections to line numbers (used for the NEA write-up).
  If you move code, update those comments.

## Run and check
```
pip install customtkinter networkx matplotlib pillow   # needs a Python build with tkinter
python Main.py
```
Checks (run all before opening a PR; in the cloud sandbox use `python3.12`, which has tkinter):
```
python3.12 -m py_compile *.py
xvfb-run -a python3.12 -c "import Main; a=Main.App(); a.update(); a.after(1500,a.destroy); a.mainloop(); print('SMOKE OK')"
```
There is no test suite or linter yet (see ROADMAP.md). Once `tests/` exists, also run `python3.12 -m pytest -q`.
